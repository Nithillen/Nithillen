### Featured Repositories & Systems

* **[Evolutionary Trading System](https://github.com/Nithillen/evolutionary_trading_system)**
  An autonomous, object-oriented algorithmic trading engine built in Python and `asyncio`. Spawns trading bots with randomized strategy indicators that undergo natural selection. Bots hitting drawdown thresholds trigger an automated kill-switch and mutate their parameters to learn from failure. Successful bots lock initial principal into an append-only "Safe Vault" and trade exclusively on house money.

* **[Patient Readmission and Resource Optimization Engine](https://github.com/Nithillen/patient_readmission_engine)**
  An end-to-end clinical data science engine modeled after MIMIC-III. Features an advanced SQL pipeline (multi-table relational JOINs, CTEs, and `LEAD()` window functions for 30-day temporal gap tracking) coupled with a balanced Random Forest classifier. Implements comprehensive SHAP explainability (beeswarm, waterfall, dependence) for clinical decision-makers.

* **[ML-Enhanced Pairs Trading](https://github.com/Nithillen/pairs_trading_ml)**
  A quantitative statistical arbitrage pipeline that identifies cointegrated equity pairs via Augmented Dickey-Fuller tests and Engle-Granger regressions. Trains an XGBoost classifier on rolling Z-score, volatility, and momentum signals to forecast spread mean-reversion, strictly architected to eliminate look-ahead bias and backtested using VectorBT.
